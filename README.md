# Arelia Online

Web MMORPG project inspired by the old prototype, rebuilt as a new game.

## Structure

- `client/` browser game client
- `server/` multiplayer WebSocket server
- `maps/` world/map definitions
- `data/` game data and configuration

## Current foundation

- Web browser client
- Real-time multiplayer architecture
- Warrior / Mage / Rogue classes
- Large-world zone layout foundation
- Data-driven quests, monsters, items and equipment
- Save/load architecture prepared for expansion

The project will be expanded system-by-system without copying the old game wholesale.
